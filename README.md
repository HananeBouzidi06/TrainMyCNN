# TrainMyCNN 🧠

An interactive CNN image classification application.

## Features
- Create custom image classes.
- Upload training images.
- Train a CNN directly in the browser.
- Customize training settings:
  - Epochs
  - Batch Size
  - Learning Rate
  - Early Stopping
  - Data Augmentation
- Visualize Accuracy and Loss.
- Test the trained model with new images.
- Export the trained model.

## Technologies
- HTML
- CSS
- JavaScript
- TensorFlow.js
- Chart.js
